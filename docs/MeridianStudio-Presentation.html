How It Works

Blueprint Feature

Per-Section AI Chatbot

Context-Aware Conversations

Each panel has its own chat icon. When opened, the chatbot automatically summarises the current panel content so the AI already knows what you're working on — no copy-pasting.

Apply Patches Directly

When the AI proposes a change, it embeds a structured <apply> block. One click applies the patch — the panel updates instantly without page reload.

Resizable Drawer

Drag to expand or narrow the chat panel. Content width adapts so the conversation never competes with the blueprint context alongside it.

Conversation Flow
System summary: "This panel covers Architecture Decisions for the FHIR Ingestion Pipeline. Current ADRs: event-driven messaging (Kafka), microservices…"
User: "The client uses Azure Service Bus, not Kafka. Update the messaging decision."
AI: "Updated. Given Azure Service Bus, I've also adjusted the resilience strategy to use dead-letter queues…"
[Apply Changes]

AI Intelligence Layer

Multi-Model Cascade with Live Fallback

Four providers, automatic rotation on quota or failure — the platform never returns a blank screen.

✨
1st — Gemini 2.5 Flash
Primary. Large context, fast. Handles research, blueprints, and documents.
Primary
⚡
2nd — Groq llama-3.3-70b
Fallback. Ultra-fast inference. Activates on Gemini quota exhaustion.
Fallback
🤖
3rd — Claude Sonnet 4.6
Second fallback. Used for documents requiring rich narrative quality.
Reserve
🔧
Heuristic Engine (Offline)
Zero-dependency fallback. Domain-aware templates for 9 industry verticals.
Offline
Real-Time Model Status

Server-Sent Events stream broadcasts every provider attempt, success, and failure. The UI shows a live status badge — "Gemini · Succeeded" — for every operation.

Streaming Responses

Blueprint generation streams token-by-token — users see content appear in real time rather than waiting for a full response. Chat responses also stream live.

IT Services Persona

Prompts include a three-layer consultant persona: Capgemini-equivalent base + domain specialisation + dimension-adaptive expertise qualifiers.
