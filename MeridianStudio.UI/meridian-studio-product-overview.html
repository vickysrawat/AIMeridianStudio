🎯 Problem Statement

Technology leaders and architects spend significant time manually synthesising market intelligence, designing system blueprints, generating implementation artefacts, and producing stakeholder documents. Each of these activities requires context-switching across multiple tools, and the quality of outputs is highly dependent on individual expertise and prompt engineering skills.

MeridianStudio solves this by providing a single, AI-orchestrated workspace that chains market research → architectural blueprinting → task execution → document generation into a cohesive workflow — backed by a multi-model LLM cascade that ensures availability even when commercial API quotas are exhausted.

The platform operates fully offline via a built-in Heuristic Engine — no API keys are required to explore the full feature set across all 9 supported industry verticals.

✨ Core Features

🔍

Trends Discovery

AI-powered market research that returns prioritised solution opportunities, competitor insights, and domain intelligence for any industry keyword.

🏗️

Architectural Blueprinter

Generates complete system blueprints including scenario narrative, topology diagrams, database schemas, REST endpoint manifests, and resilience strategies.

⚙️

Execution Pipeline

Simulates task execution with real-time progress logs, generated C# 13 code templates, and a 0–100 progress score for any engineering task.

📄

Document Studio

Produces four document types from a blueprint: Executive Summary, Market Analysis, Technical Specification, and full Proposal — all as structured Markdown.

💬

Prompt Studio

Generates developer-ready handoff prompts for any component, targeting Claude, Gemini, or Groq — complete with structured directives and quality gates.

📊

Executive Slides

Exports workspace findings as a professional PowerPoint presentation via pptxgenjs for stakeholder delivery.

📡

Real-Time Model Status

Live SSE stream shows which LLM provider is active per operation — with attempting, succeeded, failed, and fallback events as they happen.

⚡

Offline Heuristic Engine

Built-in deterministic engine covers all 9 industry verticals — the app runs without any external API keys configured.

🤖 Multi-Model LLM Cascade

Every API operation routes through a prioritised cascade. If a provider returns a 429/503 or is unconfigured, the orchestrator automatically promotes to the next tier — with zero user intervention required.

🏛️ Architecture

└── src/app/
    ├── core/
    │   ├── models/interfaces.ts       ← shared TypeScript types

    │   ├── architectural-blueprinter/ ← blueprint feature
    │   ├── execution-pipeline/        ← task execution feature
    │   ├── document-studio/           ← document generation feature
    │   ├── prompt-studio/             ← LLM prompt generation
    │   ├── executive-slides/          ← PowerPoint export
    │   └── domain-settings/           ← configuration
    └── app.routes.ts                  ← lazy-loaded standalone routes

Backend Architecture (.NET 10)

MeridianStudio.API/
└── src/
    ├── Domain/          ← entities, value objects, domain services
    ├── Application/     ← use cases, DTOs, orchestration logic
    ├── Infrastructure/  ← LLM clients, caching, SSE hub
    └── API/             ← Minimal API endpoints, middleware, OpenAPI

Key Architectural Decisions

  • Standalone components — No NgModules; all Angular components are standalone with direct imports
  • Signals-first state — Angular Signals used for reactive state instead of Subject/BehaviorSubject
  • DDD backend — Domain/Application/Infrastructure/API four-layer separation enforced
  • Response caching — Research results cached server-side; isRerun: true evicts cache
  • SSE over WebSocket — Simpler, HTTP/1.1 compatible, native browser EventSource API
  • Heuristic Engine as last resort — Guarantees deterministic output with zero external dependencies

📋 Business Rules

Research Pagination

  • Page 1 always returns exactly 5 solution items and 4 competitor insights
  • loadMore: true bypasses cache and returns 5 additional items not already in existingItemIds
  • isRerun: true evicts the server-side cache and regenerates from scratch

Caching

  • Research results are cached server-side per keyword
  • Cached responses preserve the original modelUsed value from first generation
  • Blueprint, document, and prompt endpoints do not cache by default

JSON Serialisation

  • All API responses use camelCase field names
  • Null properties are omitted from responses
  • WriteIndented: false — compact JSON

SSE Connection

  • Clients should connect once on app load using the native browser EventSource API
  • A heartbeat comment (: heartbeat) is emitted every 25 seconds to prevent proxy timeouts
  • All operations emit attempting → (failed →)* succeeded or fallback

Blueprint Fields

  • All blueprint string fields (coreScenario, baseTopology, etc.) contain Markdown
  • Newlines in JSON responses are represented as \n
  • coreScenario is guaranteed ≥ 300 words; content from document generation ≥ 600 words
